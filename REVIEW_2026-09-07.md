## Follow-up: nested equation selection

The user subsequently reported that reader equations 3--7 could not be clicked
inside the selected main theorem. The earlier browser checks verified their
geometry and navigation links, but did not click nested highlights while their
containing theorem was selected.

A new ordinary-pointer regression reproduced the failure: the theorem's
`z-index:200` intercepted clicks on equation 3. Selection no longer overrides
the geometry-based stacking order. The separate forced lowering of unmapped
highlights was also removed, so inner uncurated equations remain clickable when
the user explicitly shows those locations. Correspondence labels are unchanged.

After repair, all 79 browser checks pass locally, including equations 3--7 with
the parent theorem reselected before every click, parent reselection afterward,
desktop/mobile/200% text, and the formal paper's uncurated inner equations.
The browser tests now compare the served CSS files with the reviewed build too.
The 17 data tests, 14 graph tests, syntax checks and whitespace check also pass.
No proof data, paper bytes, highlight geometry or mathematical mappings changed.
